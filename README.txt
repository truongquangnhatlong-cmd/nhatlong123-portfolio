TRUONG QUANG NHAT LONG - PORTFOLIO

Cac thanh phan:
- index.html: Noi dung trang web.
- style.css: Giao dien va bo cuc.
- images/avatar.jpg: Anh dai dien.

Xem website tren may tinh:
1. Giai nen file ZIP.
2. Mo thu muc nhatlong-portfolio.
3. Bam dup vao index.html de mo bang trinh duyet.
4. Giu index.html, style.css va thu muc images cung vi tri.

Tai len GitHub:
1. Mo repository nhatlong-portfolio.
2. Chon Add file > Upload files.
3. Tai len index.html, style.css va thu muc images (khong can tai README.txt neu khong muon).
4. Chon Commit changes.
5. Vao Settings > Pages.
6. Trong Build and deployment, chon Deploy from a branch.
7. Chon branch main va folder /(root), sau do nhan Save.
8. Website se co dia chi:
   https://truongquangnhatlong-cmd.github.io/nhatlong-portfolio/

Ghi chu:
- Website chi su dung tieng Viet.
- Khong su dung hieu ung chuyen dong hay JavaScript.
- Anh dai dien duoc hien thi nho, dang hinh tron.
- Neu thay anh, dat anh moi ten avatar.jpg trong thu muc images.
